# Речевые субтитры и обложки v2

## Автосубтитры

В студии нажмите **Автосубтитры** (либо «Субтитры → Распознать речь из видео»). Речь распознаёт отдельный Whisper STT через OpenRouter. Это не текст из имени файла и не ответ монтажной LLM. Браузер собирает звуковую дорожку сцен с учётом обрезки, порядка и скорости; отдельная музыка не отправляется. Изображения и исходное видео остаются в библиотеке.

После подтверждения отправки звука он передаётся фрагментами до 30 секунд в WAV PCM mono 16 kHz. API проверяет длительность по WAV, а не по клиентскому числу. Запрашиваются настоящие таймкоды слов/фраз (`verbose_json`); ответ без таймкодов отвергается с возвратом кредитов, а не превращается в фиктивные субтитры. По умолчанию — Whisper large-v3, 5 кредитов за фрагмент до 30 секунд. Владелец меняет модель, цену, минимальный тариф и доступность в «ИИ и скиллы → Распознавание речи».

Нужны серверный `OPENROUTER_API_KEY` и баланс провайдера для STT. Успешный тест текстовой модели не подтверждает доступность распознавания. В админке есть отдельный тест на первых 12 секундах файла. Он использует API провайдера, но не списывает пользовательские кредиты.

Результат содержит короткие фразы и таймкоды слов. Доступны Reels с подсветкой слова, крупный контур и спокойная подложка. Одновременно видны максимум две строки; длинные фразы показываются страницами. Ручная правка текста или времени отключает устаревшие таймкоды слов именно у этой реплики. Разделение больше не дублирует весь текст в обе половины.

Весь результат применяется одной отменяемой операцией только после успешной обработки всех фрагментов. Готовые фрагменты кэшируются локально; повторный запуск не оплачивает их заново. Запросы идемпотентны на сервере. При остановке сохраняется готовая часть для продолжения; текущий запрос провайдер может завершить. Исходники не перезаписываются.

Кнопка «+» теперь добавляет пользовательское видео целиком (до лимита 180 секунд), а не молча обрезает его до шести секунд.

## Обложка

Новый конструктор предлагает три композиции: фото с акцентом, контрастная плашка и редакционная. Размер, выравнивание, расположение и цвет применяются к каждой композиции. Фото не скрывается почти непрозрачным чёрным слоем. Старые настройки затемнения нормализуются только в предпросмотре новой версии; исходное изображение не меняется.

Можно выбрать кадр вручную или получить ленту из восьми кадров. Ранжирование оценивает резкость и освещённость, а не обещает распознавание лица. Пользователь выбирает удачный кадр; ИИ при отдельном согласии может учесть выбранные кадры и реальную расшифровку и предложить три конкретных заголовка. Монтажный чат больше не должен использовать имя файла как замену содержанию. Факты, цитаты, цены и числа не выдумываются.

PNG экспортируется 1080×1920, 1920×1080 или 1080×1080. Свой фон и логотип бренд-кита сохраняются. Файл загружается через русскую кнопку; параметры композиции восстанавливаются при повторном открытии проекта.

Техническая документация STT: https://openrouter.ai/docs/guides/overview/multimodal/stt
