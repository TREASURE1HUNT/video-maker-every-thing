# VMET Admin — эксплуатация

Панель: https://video-maker-every-thing.izhanshahfarul.chatgpt.site/admin/
Исходный шаблон: https://github.com/Qualiora/shadboard (MIT). Скопированы настоящие Button/Card; оболочка адаптирована к React/Vite, сервер — Worker + D1.

## Что работает
- Пользователи: email, роль, тариф, блокировка, белый список ID моделей (или *).
- Модели: ID, провайдер, стоимость одного запроса в целых внутренних кредитах, включение.
- Балансы: начисление/списание с причиной, запрет отрицательного баланса, неизменяемый журнал операций.
- API-токены: 256 бит случайности, SHA-256 в базе, два отдельных scope, срок до 366 дней, отзыв. Полный секрет показывается один раз.
- Промокоды: бонусные кредиты, общий лимит, одна активация на пользователя, тариф, даты UTC, выключение. После использования параметры заморожены, кроме active.
- Акции: каталог предложений, тексты, аудитория, сроки, статус публикации, код. Баннеры публичного сайта и платёжные скидки пока не связаны с каталогом.
- Аудит, поиск и CSV по последним 500 записям. Показатели обзора тоже рассчитаны по этой выборке, не являются полной финансовой отчётностью.

## Доступ
Сайт сохранён приватным: внешний периметр Sites и вход ChatGPT. ADMIN_EMAIL задаётся секретом окружения; первый вход владельца создаёт его запись. Одна запись email в БД не даёт доступа через внешний периметр хостинга. Не размещайте Worker на публичном ingress, который позволяет подделывать oai-authenticated-user-email.
Роли: owner — всё; admin — всё кроме изменения владельца/других admin; finance — кредиты/промокоды/акции/аудит; support — токены/аудит; user — только клиентский API. API-токен не даёт доступа к админке.

## Подключение ИИ
1. В секретах хостинга задайте AI_GATEWAY_URL (HTTPS-адаптер) и при необходимости AI_GATEWAY_SECRET.
2. Адаптер принимает JSON контракта AI_ENDPOINT.md и возвращает {message, plan?}. Его ответственность — вызов нужного провайдера и валидация содержимого модели. Ключи провайдеров не попадают в браузер.
3. Создайте модель с точным ID и провайдером. Выдайте пользователю кредиты и токен ai:chat.
4. Откройте редактор на том же приватном домене /editor.html. Укажите endpoint https://video-maker-every-thing.izhanshahfarul.chatgpt.site/v1/chat и токен в настройках ИИ, выберите совпадающие provider/model.
5. Весь доступ и списание проверяются сервером. Нет шлюза — 503 без списания; ошибка адаптера — 502 с возвратом. Idempotency-Key обязателен, повтор успешного ключа возвращает сохранённый ответ. Повтор неуспешного ключа требует новый ключ.

Цена — фиксированные внутренние кредиты за запрос, не сырые входные/выходные токены LLM и не платёжные деньги. Внезапное завершение Worker между резервом и возвратом требует ручной сверки requests/ledger и корректировки администратором с причиной. Для коммерческого запуска нужен автоматический reconciliation и мониторинг. Реальная генерация видео/платежи не подключены этой панелью.

## Промокоды API
POST /api/redeem с Authorization: Bearer <токен promo:redeem>, JSON {"code":"WELCOME"}. Токен ai:chat для активации не подходит. Внешний периметр приватного хостинга также действует.

## Разработка
Node 24+, npm ci, npm test, npm run build. npm run db:generate создаёт только новые миграции (существующие не редактировать).
node scripts/preview-admin.mjs запускает локальную тестовую идентичность ТОЛЬКО на 127.0.0.1:4180; это не production-сервер и не публичный хостинг.
Production entrypoint: dist/server/index.js, manifest .openai/hosting.json, migrations drizzle/. Панель хранит бизнес-данные в D1, не localStorage. Локальная preview-база не переносится на хостинг.

## Резервирование
Перед коммерческим использованием настройте регулярное резервирование D1. Откат файлов не откатывает бизнес-данные и уже применённые миграции. Не удаляйте БД при откате интерфейса.
